No more certificate warningInstall this server's home certificate once on each phone. The secure address then just works, voice messages included, and an iPhone shows the WalkieTales icon on its home screen. It only covers addresses on your home network.
Download the certificate
iPhone: open this page in Safari and tap Download, then Allow. Go to Settings → Profile Downloaded → Install. Then Settings → General → About → Certificate Trust Settings and turn on WalkieTales home remote. Remove the old home-screen icon and add the secure address again.
Android: tap Download, then Settings → Security → Encryption and credentials → Install a certificate → CA certificate, and choose walkietales-home.crt.
